
  이 플러그인은 마인크래프트 서버에서 플레이어마다 고유한 스토리나 퀘스트 라인을 부여하고, 특정 행동(트리거)에 반응하여
  보상이나 메시지(액션)를 주는 시스템입니다.

  1. 스토리 흐름 및 진행 방식
   * 선형 진행 시스템: 모든 스토리는 기본적으로 순서가 정해져 있습니다. 플레이어는 현재 배정된 스토리를 완료해야만 다음
     단계로 넘어갈 수 있으며, 운영자가 강제로 순서를 바꾸지 않는 한 스토리가 꼬이지 않습니다.
   * 지능형 순서 정렬: 각 스토리 파일에 previousStory(이전)나 nextStory(다음)를 지정하면 플러그인이 자동으로 전체 스토리
     라인을 연결합니다.
   * 데이터 자동 저장: 플레이어의 현재 진행도와 퀘스트 달성 현황은 실시간으로 메모리에서 처리되며, 서버가 종료되거나
     플러그인이 비활성화될 때 자동으로 저장되어 데이터 유실을 방지합니다.

  2. 강력한 트리거(발동 조건) 시스템
  플레이어가 하는 거의 모든 행동을 감지하여 스토리를 진행시킬 수 있습니다.
   * 기본 행동: 블록 파괴, 아이템 제작, 상자 상호작용 등을 감지합니다.
   * 특정 대상 지정 (필터링):
       * 일반 블록: 특정 블록(예: 다이아몬드 원석)을 캤을 때만 작동하게 설정 가능.
       * 커스텀 블록/아이템: ItemsAdder의 커스텀 아이템 및 블록(namespace:id)을 완벽하게 인식합니다.
   * 외부 플러그인 연동 트리거:
       * MythicMobs: 특정 몬스터를 처치했을 때 발동.
       * Towny: 마을 생성, 국가 가입, 영토 확장 등 마을 시스템과 연동.
       * Quests: 다른 퀘스트 플러그인의 퀘스트를 완료했을 때 발동.

  3. 액션(실행 결과) 시스템
  트리거가 발동되면 다음과 같은 일들을 수행할 수 있습니다.
   * 메시지 전송: 플레이어 개인 또는 전체 공지로 메시지를 보냅니다. 컬러 코드(&)와 플레이스홀더를 지원합니다.
   * 명령어 실행: 콘솔 권한으로 특정 명령어를 실행합니다. (보상 지급, 칭호 부여, 이동 등 활용 가능)
   * 스토리 진행: 퀘스트 목표 수치를 올리고, 모든 목표 달성 시 다음 스토리로 플레이어를 자동 이동시킵니다.

  4. 운영 및 관리 기능
   * 실시간 설정 반영: /story reload를 통해 서버를 켜둔 채로 스토리 파일을 수정하고 바로 적용할 수 있습니다.
   * 안전한 재시작: /story restart로 데이터 저장부터 로드까지 한 번에 안전하게 수행합니다.
   * 상세한 리스트 확인: /story list로 현재 로드된 스토리들의 활성화 상태와 제목을 한눈에 볼 수 있습니다.
   * 강제 진행 제어: 운영자가 직접 플레이어의 단계를 넘기거나(next), 특정 단계로 점프(set) 시킬 수 있어 이벤트 운영이
     편리합니다.

  5. 외부 확장성 (Bridges)
   * PlaceholderAPI 연동: 서버의 스코어보드나 채팅창에 현재 스토리 제목, 진행률(%), 남은 목표 수치 등을 자유롭게 띄울 수
     있습니다.
   * 소프트 종속성 구조: 다른 연동 플러그인(ItemsAdder, Towny 등)이 없어도 에러 없이 필요한 기능만 골라서 작동하는
     유연한 구조입니다.

  6. 성능 최적화 기술
   * 랙 프리(Lag-Free) 설계: 모든 반복적인 데이터 처리는 메모리 내에서 수행되며, 무거운 리플렉션 연산은 캐싱 처리되어
     동시 접속자가 많아도 서버 리소스를 거의 차지하지 않습니다.
   * 최신 환경 최적화: Java 21 및 마인크래프트 1.21.4 환경에서 최적의 성능을 내도록 빌드되었습니다.
